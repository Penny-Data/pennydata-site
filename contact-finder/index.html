What this tool does, and its limits

You enter one website address and the tool reads that single public page, looks for a link to a contact page, and lists every email address printed on it. It does not guess addresses, crawl the rest of the site or check that a mailbox works, and it obeys robots.txt. The lookup is done by a free Hugging Face Space, so the address you type is sent there; it does not pass through PennyData. Many sites show a contact form instead of an address, or build addresses with scripts, and then you will get a contact link and no emails. Results can be outdated or point to a shared inbox, so treat them as a starting point. For long lists of sites, the bulk version on Apify runs many at once.

Questions

Does it find private or personal email addresses?

No. It only reads the public page you give it and lists addresses that are printed on it. It does not guess, generate or look up hidden addresses.

Does it check that an email address works?

No. It shows what a page publishes. It does not send mail or verify mailboxes, so an address can be outdated or go to a shared inbox.

Why did I get no emails?

Many sites use a contact form instead of printing an address, or add addresses with scripts or images that a plain page read cannot see. When that happens you still get the contact page link, if the page links to one.

Does it crawl the whole website?

No. It fetches only the one page you enter, with a 10 second timeout, and looks for a contact link and addresses on that page. It respects robots.txt and does not log in to anything.

Where does the address I type go?

It goes straight from your browser to a free Hugging Face Space that does the lookup. It does not pass through PennyData, and this site has no analytics or cookies. Hugging Face has its own privacy policy.
