# PennyData site design

Static HTML/CSS/vanilla JS. No build step, no CDN, no trackers. Pages are generated once from site-tests/build_pages.py; the HTML here is the source of truth.

## Tokens (style.css :root, dark set under prefers-color-scheme)
--bg paper, --surface, --sunk, --fg ink #111, --muted, --line, --soft, --ctext copper for text (#A4531C), --cu copper (#C8692B), --cu-wash/-wash2, --ok/--warn/--bad (+ -bg), --sh/--sh-s/--sh-h hard ink shadows, --bulk-bg/--bulk-fg. Font: Noto Sans, system-ui fallback.

## Components
Header: .top .hbar .brand .logo-m .nav (a[aria-current=page] = filled pill; pill strip on mobile)
Controls: .btn (.ghost .big .sm .busy), .chips .chip (.static), .pill (.pill-ok .pill-warn .pill-bad)
Type: .eyebrow .scribble .sec .sec-h .sec-s .fine
Home: .hero .hero-grid .hero-copy .hero-fig .bubble, .console (.console-bar .console-body .console-form .console-out .console-foot), .tools .tool (.t0-.t4) .art .fields .pv .go
Results: .status (.work .ok .err), .results .rcard .rnote, .rbar .seg, .table-wrap, .grid .thumb, .odds, .job
Content: .steps .n, .glossary, .how (details/summary FAQ)
Bulk callout: .bulk .bulk-art .bulk-note
Tool page: .thero .thero-grid .crumb .lead .tfig .panel (.embed) .row .field .actions
Footer/misc: .foot .foot-grid .foot-brand .facts .ic, .toast, .nf (404)

## Page template
header > main (.thero with crumb, h1, lead, chips + .tfig mascot > .panel tool > results > glossary/FAQ > .bulk) > footer with the AI-assistance and Apify earnings notes.

## Mascot
Inline SVG from site-tests/mascot.py: stick figure, messy ink hair tuft, solid ink hoodie, mitten hands, copper shoes. Fixed colors, so dark mode gives it a paper backdrop. Views: full (home wave), tool (tool pages, hidden on mobile), bust (cards). Faces/props vary per tool.

## Rules
Apify links one way only, with ?utm_source=pennydata-site&utm_medium=referral&utm_campaign=<tool-slug>. Card samples are labelled "example". No testimonials, counts or ratings. Footer note on every page.

## v2 changes (shared components)
- Heavy 2.5-3px ink border + hard shadow only on `.panel`, `.console` and primary `.btn`; everything else uses 1.5px `--edge` lines.
- Header: one row, `.menu-btn` toggles `.nav.open` below 1020px (common.js). One shared 7-item nav on every page.
- Footer: two lines (`.foot-notes`): built-with-AI note and the honest Apify money note. Meta previewer uses the "Some other tools here have bulk versions" wording.
- `.pal` panel-header mascot with four moods (`data-mood` idle/work/ok/err), driven by a MutationObserver on `.status` in common.js, which also scrolls to results or errors after Run.
- Result cards: `.rcard` > `.rsec` > `.recs/.rec` with per-record `.cp` copy buttons (`pdDomainCard`, `pdRecs` in common.js); TXT collapsed in `details.txt`.
- `.more` (More free tools, 6 items with prop icons), `.bulk` is the single dark Apify block per page, `.fold` collapsed glossary, `.how` divider FAQ (max 5 per tool page, 4 on home).
- Cards use prop icons (`.ico`), not the mascot bust. Full mascot only in the home hero and 404. Dark mode outlines the mascot via drop-shadow, no cream tile.
- Pages are generated by site-tests/rework.py and build_home.py from parts.py; og images by make_og.py.

## v3 update (flat ink-line pass)
- Flat language: 2px ink borders, no hard offset shadows. Spacing tokens --s1..--s8 (4,8,12,16,24,32,48,64px). .wrap is 1240px, aligned with the nav. Nav links 15px, body 17px, labels 12-13px.
- Home: top-aligned hero (h1 up to 4.4rem, underline only "headache"), uniform 4-column tool grid with a pinned "Open tool" row, real mini-previews (.mv, made-up example data, one note), an 8th mascot card, .hico icon tiles in "How free use works", FAQ first item open, honest "Who is behind PennyData?" entry. Mobile: compact 2-column grid, whole card tappable, previews hidden.
- Tool pages: .thero-grid with a mascot hero figure (hidden under 760px so the input is in the first fold), .apify-line directly under results, "What the records mean" lives in the FAQ, .actions.quick (primary "Try an example", clipboard, Clear) and .keyhint (Ctrl+U) on image and meta, .sample-prev empty-state previews.
- Footer: .foot-links nav plus the AI-assistance and honest-money notes at 13-14px ink.
- common.js: header hides on scroll down and returns on scroll up (never while focus is in the header or the nav is open); a[href="#try"] focuses #mini-in; a.ix-bm (bookmarklet) is draggable and shows a toast on click instead of trapping keys.
- Mascot moods via .pal data-mood (worried on error, happy on done); small variant on cards, one large pose per page.

## v5 (final critic pass)
- Meta previewer: passed checks collapse into `.chk-pass` details ("N passed, show them"); Page URL hint wording matches the image extractor.
- Contact finder: `.callout` about Hugging Face sits above the address field; Copy buttons stay inline on mobile.
- HN: `.hn-sum` bar is sticky with a live "N matches, showing M" count; Show more adds 25.
- Image extractor: bookmarklet href is set at runtime from `data-bm` (no javascript: URL in the HTML).
- Dark mode `--bulk-bg` is near-black (#050505) so the Apify band keeps its contrast role in both themes.
