# PennyData free tools

Live site: https://penny-data.github.io/pennydata-site/

Small browser tools, no backend: domain WHOIS and DNS lookup, extract all images from a web page, website contact finder, Polymarket odds viewer, Hacker News "Who is hiring?" search. Each links to a bulk version on Apify: https://apify.com/pennydata

PennyData earns a little from runs of the bulk versions on Apify. Written with AI assistance (Claude).

404.html loads assets through a <base> written by a tiny inline script (works at /pennydata-site/ and at a root dev server) and is noindex.
