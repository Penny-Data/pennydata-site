Extract Contact Information From a Website: Emails, Phones, Socials

How do I extract contact information from a website?

Run the Website Contact Extractor on the site's URL: it crawls the home page and contact pages and returns emails, phone numbers and social profile links per site. Export the dataset as CSV or JSON and respect each site's robots.txt and privacy law when you use the data.

Example: curl

Set APIFY_TOKEN to your Apify API token (a free account works), then run (contact extraction from two sites):

curl -s -X POST "https://api.apify.com/v2/acts/pennydata~website-contact-extractor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls":[{"url":"https://www.eff.org"},{"url":"https://www.gnu.org"}]}'

Example: Node.js

import { ApifyClient } from 'apify-client';
const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('pennydata/website-contact-extractor').call({"urls":[{"url":"https://www.eff.org"},{"url":"https://www.gnu.org"}]});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
