    What this tool does, and its limits

    You paste a page's HTML and the tool reads its title, description, canonical, Open Graph and Twitter tags. It then draws an approximate Google result and social share cards, runs a checklist for missing or too-long tags and lists every link on the page. It all happens in your browser, and the HTML is never uploaded; only preview images load from their own hosts. The previews are approximations: Google often rewrites titles and descriptions, and its real limits are measured in pixels, not characters. The tool cannot measure image dimensions or fetch a page by itself, because browsers do not let one site read another. It has no bulk version, but the other PennyData tools do.

    Questions

    Why do I have to paste HTML instead of typing a URL?

    A web page in your browser is not allowed to read another site's HTML (the browser blocks it, a rule called CORS). Fetching a URL would mean sending it through a server, and this site has none. Pasting the source keeps everything on your device. Press Ctrl+U on the page, select all, copy, paste.

    Does this show exactly how Google will display my page?

    No. It shows a close approximation. Google decides the final title and description itself, and it often rewrites them. We cut the title at about 60 characters and the description at about 160, which are common rules of thumb. Google actually limits by pixel width, so the real cut-off varies.

    What is the difference between og: tags and twitter: tags?

    Open Graph (og:) tags were created by Facebook and are read by most chat apps and by LinkedIn. X reads its own twitter: tags first and falls back to the og: tags when they are missing, so a page with good og: tags and only a twitter:card tag usually looks fine on X.

    What size should my og:image be?

    A common choice is 1200 by 630 pixels, a ratio of about 1.91 to 1, as a JPG or PNG. Use a full address starting with https://, not a relative path. This tool cannot measure image sizes, so check the file yourself.

    Why is my preview image missing here?

    Either the page has no og:image, the address is relative and you did not fill in the Page URL box, or the image could not be loaded from where it is hosted. Previews load the image straight from its host, so that host sees a request from your browser. The tool itself uploads nothing.
