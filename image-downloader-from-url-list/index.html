Image Downloader From a URL List: Get Every Image Link

How do I download all images from a list of page URLs?

Give the Website Image Extractor your page URLs, run it, and read back one row per image (image URL, alt text, width, height). It follows srcset, lazy-load attributes and CSS backgrounds, then you download the files or export the list as CSV.

Example: curl

Set APIFY_TOKEN to your Apify API token (a free account works), then run (image extraction from a page):

curl -s -X POST "https://api.apify.com/v2/acts/pennydata~website-image-extractor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls":[{"url":"https://books.toscrape.com/"}],"maxImages":50}'

Example: Node.js

import { ApifyClient } from 'apify-client';
const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('pennydata/website-image-extractor').call({"startUrls":[{"url":"https://books.toscrape.com/"}],"maxImages":50});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
