Download All Images From a Website

You want every image from a site without right-clicking one by one. Here are three working ways, from simplest to most scalable. Only download images you have the right to use, and respect each site's robots.txt and terms.

  1. Browser method (one page)

    Open the page, press Ctrl+S (Cmd+S on Mac) and choose 'Webpage, Complete'. The browser saves an _files folder with every image the page loaded. Lazy-loaded images that never scrolled into view are missing, so scroll to the bottom first.

  2. wget (whole site, command line)

    Run: wget -r -l 2 -nd -A jpg,jpeg,png,gif,webp,svg -P images https://example.com/ . This crawls two levels deep and keeps only image files in the images folder. Add --wait=1 to be polite and check robots.txt first; wget obeys it by default.

  3. Apify website-image-extractor (many pages, no code)

    Paste page URLs into the Website Image Extractor actor, run it, and export the list of image URLs or the files from the dataset. It has a free tier on Apify; you pay Apify usage only.

Bulk image downloader for a whole website

To download images in bulk from many pages, let the Website Image Extractor list every image URL (about 0.002 USD per image, failed pages free) and download the files yourself. Save this as download-images.mjs, run npm i apify-client, set your Apify token in the APIFY_TOKEN environment variable and run node download-images.mjs https://books.toscrape.com/. Node 18 or newer.

// npm i apify-client  |  node download-images.mjs https://books.toscrape.com/
import { ApifyClient } from 'apify-client';
import { mkdir, writeFile } from 'node:fs/promises';
import path from 'node:path';

const pageUrl = process.argv[2];
const outDir = 'images';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('pennydata/website-image-extractor').call({
  startUrls: [{ url: pageUrl }],
  maxImages: 100,
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();

await mkdir(outDir, { recursive: true });
let saved = 0;
for (const [i, row] of items.entries()) {
  if (!row.imageUrl) continue;
  try {
    const res = await fetch(row.imageUrl);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const ext = path.extname(new URL(row.imageUrl).pathname) || '.jpg';
    await writeFile(path.join(outDir, `${String(i).padStart(4, '0')}${ext}`), Buffer.from(await res.arrayBuffer()));
    saved++;
  } catch (err) {
    console.error(`skip ${row.imageUrl}: ${err.message}`);
  }
}
console.log(`saved ${saved} of ${items.length} images to ./${outDir}`);

Each dataset row has imageUrl, altText, width, height and contentType; add maxPagesPerStart to follow same-site links, or minWidth to skip icons. I ran the download half of this script against the public practice site books.toscrape.com (8 of 8 images saved); the actor call uses the documented apify-client API.
