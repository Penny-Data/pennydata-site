Questions, answered straight

Are these tools really free?

Yes. Each tool works without an account or payment. To keep the free tools fair for everyone they have a small hourly limit, counted in your own browser. If you need more, the bulk versions run on Apify, which is a paid service.

Where does my data go?

Lookups go from your browser straight to public data sources: dns.google and rdap.org for domains, Polymarket's public API for odds, and the Hacker News search API for job posts. HTML you paste into the image extractor or meta tag previewer stays in your browser. The contact finder embeds a Hugging Face Space, which receives the site you enter. Nothing passes through a PennyData server.

Does PennyData track me?

No analytics, no cookies and no accounts. The only thing stored is a small usage counter in your browser's local storage, so the hourly limit works.

How does PennyData make money?

From the bulk versions of these tools on Apify. If you run one, PennyData earns a share of that run. Links from this site to Apify carry a tracking tag so that is visible. The free tools are not ad-supported.

Who is behind PennyData?

PennyData is a small project that publishes free in-browser data tools and sells bulk versions of them on Apify. The site and its code were built with AI assistance (Claude). There is no team page, customer list or review score here because we have none to show, and we will not invent them.
