Bulk WHOIS Domain Lookup: Check Many Domains at Once

How do I run a bulk WHOIS lookup for a list of domains?

Paste your domains into the Bulk WHOIS and DNS Lookup actor and run it: you get registrar, creation and expiry dates, nameservers and DNS records for each domain as JSON or CSV. No account with a WHOIS provider is needed; it uses public RDAP data.

Example: curl

Set APIFY_TOKEN to your Apify API token (a free account works), then run (WHOIS lookup of three domains):

curl -s -X POST "https://api.apify.com/v2/acts/pennydata~bulk-domain-whois-dns-lookup/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains":["python.org","github.com","wikipedia.org"]}'

Example: Node.js

import { ApifyClient } from 'apify-client';
const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('pennydata/bulk-domain-whois-dns-lookup').call({"domains":["python.org","github.com","wikipedia.org"]});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
